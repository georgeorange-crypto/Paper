## 缺失项 / 说明

- **作业题面与 starter 代码**：官网 assignments.html 未公开发布 HW1–HW3 的 PDF 题面或代码仓库（仅面向选课学生通过 Gradescope 分发），公开可得的只有 LaTeX 模板。三次作业各占 15%。
- **官方讲义仍在建设中**：在线讲义只覆盖前 5 个主题（引言/自回归/VAE/Flow/GAN），能量模型、分数模型等章节尚未成文。源码仓库：https://github.com/deepgenerativemodels/notes 。
- **考试**：本课程无考试，成绩由作业 + 课程项目构成，故无 `exams/` 目录。
