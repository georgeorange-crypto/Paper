# Stanford CS329H：从人类偏好中学习（Machine Learning from Human Preferences）

## 课程简介
斯坦福大学 CS329H，主题为**从人类偏好中进行机器学习**（即对齐 / RLHF 方向）。课程融合六大领域的机制来优化服务于人类的系统：心理测量学（psychometrics）、离散选择（discrete choice）、强化学习、信息检索、规范理论（normative theory）与现代语言建模。核心主题包括：选择建模、RLHF、直接偏好优化（DPO）、辅助博弈（assistance games）、多臂老虎机（bandits）、行为偏差、以及偏好聚合与公平性。

课程分为五个单元：Foundation（基础）、Learning（学习）、Action（行动）、Inversion（反演）、Aggregation（聚合），共 18 讲。
