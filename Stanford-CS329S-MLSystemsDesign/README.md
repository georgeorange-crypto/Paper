# Stanford CS329S：机器学习系统设计（Machine Learning Systems Design）

## 课程简介
斯坦福大学 CS329S，聚焦于**机器学习系统的端到端设计与部署**，涵盖从需求理解、训练数据、特征工程、模型开发与离线评估，到部署、监控、数据分布漂移、持续学习与 ML 基础设施等生产环境全流程。课程以实战项目为核心，无传统作业与考试。

- **授课教师**：Chip Huyen（黄智鹏）及多位业界客座讲者
- **官方网站**：https://stanford-cs329s.github.io/
- **课程大纲**：https://stanford-cs329s.github.io/syllabus.html
- **教材**：Chip Huyen《Designing Machine Learning Systems》(O'Reilly)
- **YouTube 播放列表**：无官方完整播放列表（仅有个别客座讲座与 Demo Day 录像散见于 YouTube）

## 缺失 / 未包含项
- **作业与考试**：本课程无独立作业或考试，成绩以季度长的实战项目为主，故无 `assignments/` 与 `exams/` 目录。
- **部分讲座无讲义**：第 7、9、11–16 讲仅有幻灯片或第三方教程链接，无对应课堂讲义。
- **教程 Notebook**：部分教程（Ray Serve、Evidently、WhyLogs 等）以外部 GitHub/Colab notebook 形式提供，未纳入下载，可按大纲中链接自取。
- **视频**：按要求未下载任何视频。
