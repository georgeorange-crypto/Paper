# Berkeley CS294/194-196 —— Agentic AI / Large Language Model Agents (LLM Agents MOOC)

## 课程信息

- **课程名称**: Advanced Large Language Model Agents / Agentic AI（伯克利 CS294-280 及 LLM Agents MOOC）
- **主讲教师**: Dawn Song（宋晓冬）、Xinyun Chen（陈昕昀），以及众多客座讲者
- **开课单位**: UC Berkeley RDI (Center for Responsible, Decentralized Intelligence)
- **官方网站**:
  - 项目主页: https://rdi.berkeley.edu/agentic-ai/ （现已跳转至 f25 学期页面）
  - MOOC 主页: https://llmagents-learning.org/
  - Fall 2024 (基础篇, prerequisite): https://llmagents-learning.org/f24
  - Spring 2025 (进阶篇, Advanced): https://llmagents-learning.org/sp25
- **YouTube**: 官方未提供单一合集 (playlist) 链接。每讲的直播回放各自托管在 YouTube 上，格式为 `youtube.com/live/<id>`。频道为 Berkeley RDI。各讲直播链接见下表「视频」列，供后续视频下载环节使用。
- **Discord**: https://discord.gg/NWVpQ9rBvd

> 说明: 本课程分两个学期。Fall 2024 为基础篇（LLM 推理、agent 概述、AutoGen/DSPy、软件/企业 agent、机器人等）；Spring 2025 为进阶篇（推理训练、多模态 agent、形式化数学证明、安全等）。两学期幻灯片均已下载。
