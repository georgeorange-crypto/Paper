# 剑桥大学 L46：机器学习系统原理（Principles of Machine Learning Systems）

## 课程简介
剑桥大学计算机实验室研究生课程 L46，聚焦**机器学习系统的底层原理**：从 ML 系统全景、模型压缩、自动微分、训练内部机制，到 GPU 与 CUDA、硬件加速等。课程以实践项目为核心评估方式。

> **说明**：材料实际托管于剑桥课程站点的 `MLSysPtic`（ML Systems Practical）路径下（`https://www.cl.cam.ac.uk/teaching/2324/MLSysPtic/`），本 README 表格列出的即该 2023–24 学年版本的文件。

- **主讲教师**：Dr Nic Lane
