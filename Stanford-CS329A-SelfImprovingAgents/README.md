# Stanford CS329A：自我改进的 AI 智能体（Self-Improving AI Agents）

## 课程简介
斯坦福大学 CS329A（2025 秋季学期）是一门前沿研讨课，主题为**能够通过与自身及环境交互而持续自我改进的 AI 智能体**。内容涵盖：测试时计算扩展（test-time compute scaling）、稳健验证、借助工具/代码从反馈中学习、多步推理与规划、训练时扩展与强化学习扩展、自我改进智能体的开放式演化、深度研究智能体、软件工程智能体框架、智能体记忆增强、智能体评估与长程任务等。

- **授课教师**：Aakanksha Chowdhery、Azalia Mirhoseini
- **客座讲者**：Melvin Johnson、Denny Zhou、Thang Luong（Google DeepMind）、Junchen Jiang（UChicago/LMCache）、Misha Laskin（Reflection AI）、Danny Driess（Physical Intelligence）等
- **官方网站**：https://cs329a.stanford.edu/
- **YouTube 播放列表**：无（课程页面未提供任何录播视频）
